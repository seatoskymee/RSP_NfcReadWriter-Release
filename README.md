# RSP NFC Read/Writer - Release

Android NFC Tag Reader/Writer APK 배포 저장소

## 최신 버전
**v1.0.11** (debug build)

## 다운로드
[RSP_APK_NfcReader_v1.0.11_debug.apk](https://github.com/seatoskymee/RSP_NfcReadWriter-Release/releases/download/v1.0.11/RSP_APK_NfcReader_v1.0.11_debug.apk)

## 주요 기능
- NFC 태그 정보 읽기 (MIFARE Classic/Ultralight/NTAG, ISO 15693, FeliCa, IsoDep)
- 메모리 읽기/쓰기 및 보호 설정 분석
- NDEF 태그 감지 시 BLE OOB 자동 페어링
- Tag 지원 현황 및 도움말
- Background NFC 자동인식 옵션
